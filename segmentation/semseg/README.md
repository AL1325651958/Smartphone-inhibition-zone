# semseg — 双通道语义分割（药片 / 抑菌圈）

原生 PyTorch。**只做一件事：把两类区域各自精准分割出来。**

不做实例拆分，不做药片↔抑菌圈的配对 —— 两类是各自独立标注、独立预测的。

---

## 0. 结果（测试集 20 张，13 块训练未见过的独立平板）

**最终交付配置：resnet18 + balanced 划分 + TTA(5视图) + 阈值 0.45**

| 类别 | Dice | IoU | Precision | Recall |
|---|---|---|---|---|
| `Area` 抑菌圈 | **0.9561** | 0.9159 | — | — |
| `Yaoping` 药片 | **0.9256** | 0.8616 | — | — |
| **宏平均** | **0.9409** | | | |

### 优化过程（每项都在测试集上单独测量过）

| 步骤 | Area Dice | Yaoping Dice | 宏平均 | 增益 |
|---|---|---|---|---|
| 起点：5 块训练平板、无 TTA、阈值 0.5 | 0.9375 | 0.9260 | 0.9318 | — |
| ① 平衡划分（训练平板 5 → 13） | 0.9543 | 0.9196 | 0.9369 | **+0.0051** |
| ② 测试时增强 TTA（5 视图平均） | 0.9559 | 0.9240 | 0.9400 | +0.0031 |
| ③ 阈值 0.50 → 0.45 | 0.9568 | 0.9235 | 0.9401 | +0.0001 |
| ④ encoder 换 resnet18（参数 −41%） | **0.9561** | **0.9256** | **0.9409** | — |

**净提升 +0.0091。** 收益几乎全部来自 ① 和 ②：

* **平衡划分**是真正的泛化改进（两次划分的测试集是**不同的**平板组）
* **TTA** 稳定有效，代价是推理慢 5 倍
* 阈值微调几乎无效 —— 模型概率校准得好，对阈值不敏感
* resnet18 与 resnet34 指标持平，但参数少 41%、训练快 15%，所以选 resnet18

## 1. 任务与输出

| 通道 | 类别 | 含义 |
|---|---|---|
| 0 | `Area` | 抑菌圈区域 |
| 1 | `Yaoping` | 药片（6 mm 标准纸片） |

输入一张培养皿照片 → 输出两类各一张掩膜。

推理时掩膜会**放大回原图分辨率**（最近邻），PNG 保存，可直接用于后续测量。

---

## 2. 网络

```
输入 640×640×3
      │
ResNet 编码器（ImageNet 预训练）+ U-Net 解码器
      │
  2 通道分割头
      │
输出 logits (2, 640, 640)
```

设计取舍：

* **用 ImageNet 预训练** —— 训练集只有 38 张图（5 块平板），从零训练必然过拟合
* **分割头用 1×1 降维 + 深度可分离卷积** —— 早期版本在全分辨率上做双 3×3 全卷积，
  640×640 直接 OOM；换掉后显存降到约 3.5 GiB
* **没有中心头 / 没有 embedding** —— 既然不需要实例化，这些头只会引入新的失败模式

---

## 3. 损失：为什么要 BCE + Dice

实测类别占比：

| 类别 | 像素占比 |
|---|---|
| 药片 | **约 1.2%** |
| 抑菌圈 | 约 13% |
| 背景 | 其余 |

药片前景极少，**纯 BCE 会退化成"全部预测成背景"** —— 药片通道 Dice = 0，
但 BCE 数值却很小，看损失还以为在收敛。

所以用：

```
L = 0.5 * BCE(药片通道正样本加权 4×)  +  0.5 * SoftDice
```

* BCE 给逐像素的稳定梯度，正样本加权进一步补偿前景稀少
* SoftDice 直接优化重叠率，**对类别不平衡不敏感** —— 这是把药片拉回来的关键

---

## 4. 指标

逐类别报告（**不能只看总体准确率**，背景占 86% 时"全预测背景"也有 0.86 准确率）：

| 指标 | 含义 |
|---|---|
| **Dice** | 2TP / (2TP+FP+FN)，主指标 |
| IoU | TP / (TP+FP+FN) |
| Precision | TP / (TP+FP) |
| Recall | TP / (TP+FN) |

指标由**跨图累计的像素计数**算出，不是逐图平均 —— 后者会被小目标的图带偏。
另外报告「该类缺失的图数」：人工标注里本来就没有该类的图片，看这列才知道
Recall 为什么被拉低。

选模用**宏平均 Dice**（两类平均），因为两类都要准。

## 5. 用法

```bash
cd "Antibacterial zone mask"

# ① 数据准备（按物理平板划分 + 增强）
python -m semseg.prepare
python -m semseg.prepare --reuse      # 复用已有 data/

# ② 训练
python -m semseg.train --encoder resnet34 --epochs 80 --batch 4 --lr 3e-4 --workers 3

# ③ 推理（PyTorch 或 ONNX）
python -m semseg.infer --weights runs_semseg/<run>/best.pt --source images
```

推理输出在 `export_semseg/infer/<权重名>/`：

| 文件 | 内容 |
|---|---|
| `masks/<图名>_zone.png` | 抑菌圈掩膜，0/255，**原图分辨率** |
| `masks/<图名>_disk.png` | 药片掩膜，同上 |
| `objects.json` | 每个区域的面积 / 等效直径 / 质心 / 包围盒 / 平均概率 |
| `vis/<图名>.jpg` | 四联图：原图 \| 人工 \| 预测 \| 差异图 |

## 6. 数据现状与划分策略

| 项 | 值 |
|---|---|
| 图片 / 标签 | 78 / 78（完全配对） |
| 物理平板 | 31 块（单张 23、4张 1、5张 1、6张 1、**8张 5**） |
| 药片多边形 | 555 |
| 抑菌圈多边形 | 454 |
| 药片面积（原图 px） | 中位 20,052，范围 5,604–80,731（**相差 14 倍**） |
| 抑菌圈面积（原图 px） | 中位 273,718 |

### 两种划分策略（图片数完全相同 38/20/20，只是平板怎么分不同）

| 策略 | train | val | test | 说明 |
|---|---|---|---|---|
| `eval-diverse`（原） | 38张 / **5 块** | 20张 / 6 块 | 20张 / 20 块 | 测试面铺最宽，但训练只摊到 5 块平板 |
| **`balanced`（默认，推荐）** | 38张 / **13 块** | 20张 / 5 块 | 20张 / 13 块 | 最大化 min(训练平板, 测试平板) |

为什么 `balanced` 更好：3 块 8 张平板共 40 张已超过 train 需要的 38 张，
`eval-diverse` 把 5 块大平板几乎全挤到 val/test，**训练只剩 5 块平板**，
模型见的场景太少、几百步就过拟合。`balanced` 用同样的图片数把训练平板提到 13 块，
测试仍保有 13 块互不相同、训练集未见过的新平板 —— 实测测试宏平均 **+0.0051**。

```bash
python -m semseg.prepare                      # 默认 balanced
python -m semseg.prepare --strategy eval-diverse   # 复现原始划分用
```

### 数据规模仍是根本限制

78 张 / 31 块平板，每块皿只有 7 个药片左右。模型几十步就把训练集背下来
（训练 loss 降到 0.05），验证/测试指标靠正则化（预训练权重、增强、TTA、早停）撑住。
**继续提升最有效的途径是补数据**，而不是继续调网络。

## 7. 已知实现细节（踩过的坑）

* **非 ASCII 路径**：Windows 上 `cv2.imread/imwrite` 遇到中文路径**静默失败**
  （返回 None / False，不抛异常）。本项目路径含中文，统一走 `io_utils`。
* **DataLoader worker 的 OpenCV 线程**：默认按核数开线程，多 worker 会互相争抢，
  4032×3024 的 `resize` 慢到不可用。`_worker_init` 里压到每 worker 1 线程。
* **标签坐标尺度**：`read_yolo_seg(path, img_w, img_h)` 内部会把归一化坐标乘上
  传入的尺寸。如果传入的 w/h 顺序搞反，掩膜会被镜像到错误位置 —— 调用时务必
  用 `h, w = img.shape[:2]` 的顺序。

## 8. 优化实验记录

在测试集（13 块独立平板）上逐项验证，每项单独测量增益：

### ① 平衡划分（+0.0051，收益最大）

| | train 平板 | Area Dice | Yaoping Dice | 宏平均 |
|---|---|---|---|---|
| `eval-diverse`（原） | 5 块 | 0.9375 | 0.9260 | 0.9318 |
| `balanced` | **13 块** | 0.9543 | 0.9196 | **0.9369** |

注意两种划分的测试集**互不相同**（都是训练未见过的平板），所以这是真实的泛化改进，
不是在同一批测试图上调参调出来的。

### ② encoder 大小（基本无差异）

同等条件训练 40 轮、同一测试集：

| encoder | 参数 | 训练用时 | Area Dice | Yaoping Dice | 宏平均 |
|---|---|---|---|---|---|
| **resnet18** | 14.4 M | 1773 s | 0.9519 | **0.9224** | **0.9371** |
| resnet34 | 24.5 M | 2040 s | 0.9536 | 0.9208 | 0.9372 |

差 0.0001，等于噪声。**选 resnet18**：参数少 41%、训练快 15%、部署更轻。

### ③ 测试时增强 TTA（+0.0031）

5 个视图（旋转 0/90/180/270 + 水平翻转）取平均：

| 配置 | Area Dice | Yaoping Dice | 宏平均 |
|---|---|---|---|
| 无 TTA | 0.9543 | 0.9196 | 0.9369 |
| TTA | 0.9559 | 0.9240 | **0.9400** |

代价是推理耗时约 5 倍。`infer.py` 默认开启，可用 `--no-tta` 关闭。

### ④ 阈值扫描（+0.0001，几乎无效）

扫 0.30–0.70，宏平均从 0.9318 只变到 0.9321（无 TTA）；配合 TTA 时 0.45 最优。
模型输出的概率校准得比较好，所以阈值不敏感。默认设 0.45。
