# 进一步优化结果

## 结果汇总（同一个批次留出测试集，28 张）

| 方案 | 参数 | 测试准确率 | macro-F1 |
|---|---|---|---|
| PillCNN@112，不增强 | 2.85M | 0.214 | 0.097 |
| PillCNN@112 + 增强（旧） | 2.85M | 0.750 | 0.757 |
| **PillCNN@112 + 增强 + EMA 修正** | 2.85M | 0.821 | **0.815** |
| PillCNN@224 + 增强 | 2.85M | 0.571 | 0.495 |
| DiskNet-tiny@224 | 1.50M | 0.786 | 0.733 |
| **DiskNet-small@224** | **3.88M** | **0.857** | 0.811 |
| DiskNet-base@224 | 9.43M | 0.821 | 0.840 |
| DiskNet-small@224 + 5 视图 TTA | 3.88M | 0.929 | 0.881 |
| 4 个种子集成 + TTA | 15.5M | 0.893 | 0.871 |
| **5 个种子集成 + TTA** | 19.4M | **0.929** | **0.911** |

**从最初的 0.821 提升到 0.929（准确率）/ 0.815 提升到 0.911（macro-F1）。**

## 三个提升来源

### 1. 修掉了我自己的 EMA bug（+0.071 准确率）

第一版 PillCNN@112 用的是 `EMA=0.999`，但我只训练 80 epochs × 25 batch = **2000 次更新**，
`0.999^2000 ≈ 0.135` —— EMA 权重几乎还停在初始化附近。

改成 `EMA=0.95` 后：PillCNN@112 从 **0.750 → 0.821**。

> 教训：EMA 衰减必须按**总更新步数**来设，不能照搬大模型的值。

### 2. 新网络 DiskNet（+0.036）

按 YOLO-cls 的**思想**（不是架构）专门为这个任务设计的：

| 设计 | 理由 |
|---|---|
| **多尺度融合**：4 个 stage 各自池化后加权融合 | 判别信号是几像素高的印刷字，最后一层 7×7 已丢失细节，所以要保留浅层 56×56 的特征 |
| **高通分支**（DoG 差分）注入 stem | 字是细笔画，显式给网络一个边缘先验 |
| **BN + SiLU**（借自 YOLO） | 批次间外观差异大，需要强归一化 |
| **可学习尺度门控** | 自动决定信任哪个分辨率 |
| **SPPF** | 多感受野上下文 |

对照实验（**同分辨率 224、同 EMA 0.95、同 80 epochs、同划分**）：

- PillCNN@224：**0.571**
- DiskNet-small@224：**0.857**

**+0.286。** 所以提升来自架构，不是分辨率 —— 事实上 PillCNN 在 224 上反而变差了
（0.821@112 → 0.571@224），而 DiskNet 在 224 上更好。

### 3. TTA + 集成（+0.072）

**TTA 收益很大**：DiskNet-small 单模型 0.857 → **0.929**（+5 个视图：原图 + 水平翻转 +
垂直翻转 + ±10° 旋转）。磁盘在培养皿上的朝向是任意的，翻转/旋转视图确实带来互补信息。

**5 个种子集成**：单模型准确率在 0.750–0.964 之间波动（测试集只有 28 张，方差大），
集成把均值拉到 **0.929**，macro-F1 **0.911**，cross-seed 波动被明显压平。

## 仍然存在的两个硬约束

**1. 测试集只有 28 张。** 一个样本对错就是 ±3.6 个百分点。0.929 这个数字的置信区间很宽，
跨种子单模型能到 0.750–0.964 就是证据。**建议把留出批次从 5 个增加到 10 个以上。**

**2. DA（11 片）和 E（8 片）样本太少。** 这两类的指标基本没有统计意义。要得到可信的
单类结论，每类至少需要 30+ 片独立药片。

## 复现

```powershell

# 224 数据集
python augment_dataset.py --n-train 8 --n-val 2 --n-test 0 --img-size 224 \
    --out dataset_augmented224
```

## 下一步还能做什么

1. **扩测试集**（优先级最高）：多留 4–5 个批次，把 0.929 的置信区间压窄。
2. 补标 DA / E 到每类 30+ 片。
3. 试 DiskNet-base 的多种子集成（当前只集成了 small）。
4. 用一次**独立复现划分**跑完整集成流程，确认 0.929 不是主划分的运气。
