# 为什么其他批次的数据那么少？

## 直接答案

因为**每个批次贡献多少图，完全由它进入数据集的药片数决定**，而每片药片被固定
扩增成 151 张：

> **贡献图数 = 药片数 × 151**

所以药片少的批次，图数就按比例少：

| 批次 | 药片数 | 图数 | 占全数据 |
|---|---|---|---|
| 063258 | 26 | 3926 | **43.3%** |
| 062940 | 11 | 1661 | 18.3% |
| 063155 | 6 | 906 | 10.0% |
| 063229 | 3 | 453 | 5.0% |
| 063331 | 3 | 453 | 5.0% |
| 062802 / 063644 / 063431 | 各 2 | 各 302 | 各 3.3% |
| 063913 / 063400 / 064156 / 063121 / 064101 | 各 1 | 各 151 | 各 1.7% |

**3 个批次就占了 72% 的图像；5 个批次各只占 1.7%。**

## 数据是怎么变成这样的

原始采集其实有 **25 个拍摄会话、137 张裁剪图**（每次拍摄 4–8 张，典型培养皿
就是 7 个药片纸片）：

| | 数量 |
|---|---|
| 原始拍摄会话 | 25 |
| 原始裁剪图 | 137 |
| **进入类别数据集的药片** | **60（43.8%）** |
| 未被采用的裁剪图 | 77（56.2%） |

**所以类别数据集是从原始采集里"挑出来"的子集，不是全部原始数据。**
60 片药片来自其中 13 个会话（我按文件名和图像匹配回溯确认）。

## 关键发现：挑选标准不一致，放大了缺陷

我统计了原始裁剪图的边长，发现 **12/25 个原始会话本身拍的就偏小（中位 104–176 px）**：

| 会话 | 原始裁剪中位边长 | 进入数据集的药片 |
|---|---|---|
| **063258** | **104 px** | **26 片** ← 例外 |
| 063849 | 126 px | 0 片 |
| 064215 | 126 px | 0 片 |
| 063617 | 138 px | 0 片 |
| 064101 | 138 px | 1 片 |
| 063946 / 064042 | 145 px | 0 片 |
| 063913 / 064133 / 064244 | 151 px | 1 / 0 / 0 片 |
| 063535 / 064156 | 176 px | 0 / 1 片 |

进入数据集的绝大多数是 **202–227 px 的大裁剪**（清晰可读）。
其它小裁剪会话基本都被舍弃了 —— **但 063258 的小裁剪（104–112 px）却全部保留，
还每片扩增成 151 张，最终变成 43% 的数据量。**

这就是问题的根源：

1. **每个批次被固定扩增到 151 张/片**，不管这张原图质量好坏。
   质量差的批次不是被丢弃，而是被"放大"了 150 倍。
2. **小裁剪会话里只保留了一个（063258）**，而它恰好是质量最差的那个。
3. 结果：全数据里 **43% 是不可读的小图**，而剩下的可读批次每个只有 1–2 片药片。

## 这对训练意味着什么

| | 数量 |
|---|---|
| 独立药片（真正独立的样本） | **60 片**（不是 9060 张） |
| 每类药片数 | 8–9 片 |
| 参与留一批次交叉验证时每折每类药片 | **2–4 片** |
| 3 个批次占全数据 | 72% |

**9,060 张图里没有 9,060 个独立样本 —— 只有 60 个。**
每片药片的 150 张增强图彼此高度相关，不提供新的统计信息。

这解释了两件事：

- **为什么去掉 063258 后准确率没涨**（72.5% → 77.6%）：它虽然图不可读，但同时
  提供了 26 片药片（43% 的训练信号），删掉它等于砍掉近一半训练数据。
- **为什么单类性能波动大**：P 类只出现在 5 个批次，剔掉 063258 后某折训练集里
  P 只剩 1–2 片药片，召回率从 0.505 掉到 0.212。

## 建议（按重要性）

1. **重新裁剪，而不是删数据**。063258 的原始裁剪只有 104–112 px 是因为裁剪时
   取的范围太小；从 `链球菌检测/` 原图按统一标准（磁盘占画面固定比例，目标
   200–260 px）重裁，既保住这 26 片药片，又让字迹可读。这比删掉它更好。
2. **降低/取消均匀扩增**。每片固定 150 张放大了个体缺陷；应按质量决定是否保留，
   并让各批次贡献更均衡。
3. **补采批次**。当前每类只有 8–9 片独立药片、每折 2–4 片，这是性能的天花板。
   每类 10+ 个独立批次远比增加单批次图像数有效。
4. 稿件里应明确写：数据集含 **60 片独立药片、13 个采集批次**，图像数为 9,060
   但有效样本量是 60 —— 否则审稿人会误以为有 9,060 个独立样本。
