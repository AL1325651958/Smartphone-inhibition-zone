## 二、模型结构 DiskNet-small（3.89 M 参数）

专门为"识别磁盘上几像素高的印刷字"设计，借鉴 YOLO-cls 的思想而非架构。

```
输入 224×224×3
├── HighPass          固定 DoG 差分（σ=1.0 / 2.5）→ 1×1 conv → 16ch
├── stem              Concat(输入, HighPass) → Conv3×3 s2 → Conv3×3
│                     224 → 112
├── stage1            2 × ResBlock(32)              @ 112×112
├── down2 + stage2    Conv3×3 s2 → 2 × ResBlock(64) @ 56×56
├── down3 + stage3    Conv3×3 s2 → 2 × ResBlock(128) @ 28×28
├── down4 + stage4    Conv3×3 s2 → 2 × ResBlock(256) @ 14×14
├── SPPF              三层 5×5 最大池并联 → concat → 1×1 conv
└── head              每个 stage 池化 → 4 个 128 维 token
                      → 可学习尺度门控（softmax 加权）→ 加权和
                      → Dropout(0.3) → Linear(128 → 7)
```

- 每个卷积块：`Conv2d → BatchNorm → SiLU`
- 每个 ResBlock：`BN+SiLU → 3×3conv → BN → 通道注意力(SE) → 残差`
- **关键设计**：4 个 stage **全部**送入 head。判别信号是几像素高的字，最后一层 14×14 已丢失细节，所以保留浅层高分辨率特征并让网络自己学习信任哪个尺度。

## 三、训练设置

| 项目 | 值 |
|---|---|
| 优化器 | AdamW |
| 学习率 | 2×10⁻³ |
| 权重衰减 | 5×10⁻⁴ |
| 调度 | 线性 warmup 4 epochs → 余弦退火到 0 |
| epochs | **80** |
| batch size | 32 |
| 采样 | 类别平衡（`WeightedRandomSampler`，按逆频率） |
| 损失 | 交叉熵 + label smoothing 0.05 |
| EMA | 衰减 **0.95** |
| 梯度裁剪 | max norm 5.0 |
| 混合精度 | `torch.amp` autocast + GradScaler |
| checkpoint | 按**验证集 macro-F1** 选 epoch（非最后一个） |
| BN 处理 | **每次评估前用训练集重新统计 running stats** |
| 随机种子 | 5 个独立种子（0–4），softmax 概率平均 |
| 在线增强 | RandomAffine(±12°, 平移 4%, 缩放 0.94–1.06) + ColorJitter(0.12) |
| TTA | 5 视图：原图、水平翻转、垂直翻转、−10°、+10° |

### 两个必须记录的坑（都影响结果）

**① EMA 衰减要按总步数设。** 最初用 0.999，但总共只有 2000 次更新，
`0.999²⁰⁰⁰ ≈ 0.135` —— EMA 权重几乎停在初始化附近，结果只有 0.750。
改成 0.95 后升到 **0.821**。

**② BatchNorm 动量不能用 YOLO 的 0.03。** 每个 epoch 只有 25 个 batch，
running stats 严重滞后，导致 train 100% / val 8% 的灾难性过拟合。
改用标准动量 0.1，并在每次评估前重算统计量。

### 三个提升来源的量化

| 变化 | 增益 |
|---|---|
| 修 EMA bug（0.999 → 0.95） | +0.071 |
| 换架构（PillCNN@224 0.571 → DiskNet-small@224 0.857） | **+0.286** |
| TTA（0.857 → 0.929） | +0.072 |
| 集成（macro-F1 0.881 → 0.927，准确率持平） | 稳定性 |

**注意**：PillCNN 在 224 上反而比 112 差（0.821 → 0.571），而 DiskNet 在 224 上更好。
说明多尺度融合的设计对高分辨率输入更有效。

## 六、适用的局限性（必须写进论文）

1. **测试集只有 28 张**（5 个批次）。单模型跨种子波动 0.750–0.964，
   说明 0.929 的置信区间很宽。建议把留出批次增到 10 个以上再定稿。
2. **DA（11 片）和 E（8 片）样本过少**。E 在测试集只有 1 张，那个 F1=1.000
   没有统计意义。单类结论需要每类 30+ 片独立药片。
3. **所有数字来自单一采集中心**的 27 个批次，跨中心泛化未验证。
4. 增强图**不增加独立样本量**：有效样本数仍是 87 张训练原图，不是 783。

## 七、复现

```powershell
$env:PYTHONPATH="..\_tools\pylibs"

# 1. 224 数据集（按批次分层划分 + 离线增强）
python augment_dataset.py --n-train 8 --n-val 2 --n-test 0 --img-size 224 \
    --out dataset_augmented224

# 2. 单模型
python train_disknet.py --data dataset_augmented224 --run-name disknet224_small \
    --variant small --img-size 224 --epochs 80 --ema 0.95

# 3. 5 个种子
python train_seeds.py --variant small --seeds 0 1 2 3 4 --epochs 80

# 4. 集成 + TTA 评估
python ensemble_eval.py --runs ens_small_s0 ens_small_s1 ens_small_s2 \
    ens_small_s3 ens_small_s4 --tta 5

# 5. 汇总
python collect_training_details.py
```
